# 🧮 Calculadora em C

> Projeto acadêmico desenvolvido para a disciplina de **Bases de Programação**, com o objetivo de aplicar estruturas de programação, algoritmos, funções e lógica utilizando a linguagem C.

---

## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma **calculadora para uma loja virtual**, implementada em linguagem C.

A aplicação deverá calcular o **preço total de uma compra**, considerando o preço do produto e o valor do frete, que será definido de acordo com a **região de entrega e o peso do produto**.

---

## ❓ O que é o Projeto?

A proposta é desenvolver uma aplicação capaz de representar parte do processo de compra de uma loja virtual.

A calculadora deverá receber informações sobre o produto e a entrega, realizar os cálculos necessários e apresentar ao usuário um resumo da compra.

### 🚚 Regra de cálculo do frete

| Região | Até 2 kg | Acima de 2 kg |
|---|---:|---:|
| 🟢 Sul | R$ 30,00 | R$ 50,00 |
| 🔵 Sudeste | R$ 25,00 | R$ 45,00 |
| 🟡 Norte | R$ 35,00 | R$ 55,00 |
| 🟠 Nordeste | R$ 40,00 | R$ 60,00 |

> **Observação:** produtos com peso de até **2 kg**, incluindo exatamente 2 kg, utilizam o valor padrão. O segundo valor é aplicado somente quando o peso for **maior que 2 kg**.
